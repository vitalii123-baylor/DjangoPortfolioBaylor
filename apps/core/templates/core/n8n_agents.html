▸ AGENT_CODE

Each n8n agent is a self-contained webhook microservice written in JavaScript. The code below shows the core logic inside each agent — what data it receives, how it transforms it, and what it returns to the Orchestrator.

Intake Agent — receives raw unstructured text from the Google Sheet (e.g. "fix leaking pipe, urgent, 76706"). Sends it to Gemini AI, then cleans the markdown from the response and returns structured JSON: { services, zip, urgency, client_name, client_email }.
Pricing Agent — receives the structured job object, looks up each service in a price catalog, adds a zip-based travel fee, and applies a 25% rush surcharge if urgency is "high". Returns a clean pricing breakdown with the final total.
Scheduling Agent — reads the client's preferred days from the original webhook input (via node reference), filters the available slot list, and returns the top 3 matching slots. The node reference trick is needed because the HTTP Request node would otherwise overwrite $json.
Comms Agent — builds a context-aware prompt for Gemini based on whether the email goes to ops (internal alert) or client (booking confirmation). It injects job, pricing, and scheduling data into the prompt so Gemini writes a fully personalised email.
JSON Cleaner — Gemini often wraps its output in markdown code fences (```json ... ```). This utility node strips those fences before JSON.parse(), preventing silent failures downstream. A small but critical guard used in every agent that calls Gemini.
Intake agent.json · Code in JavaScript 
// Clean Gemini raw output → parse JSON
const raw = $json.content?.parts?.[0]?.text
           || $json.text
           || "";

const cleaned = raw
  .replace(/```json\s*/i, "")
  .replace(/```\s*$/i, "")
  .trim();

let obj;
try {
  obj = JSON.parse(cleaned);
} catch (e) {
  throw new Error(
    "Gemini output not valid JSON after cleaning. Raw: " + raw
  );
}

return [obj];
Agent-Pricing.json · Code in JavaScript 
const services = $json.body.services
  || ($json.body.service ? [$json.body.service] : []);
const zip      = $json.body.zip      || "unknown";
const urgency  = $json.body.urgency  || "low";
const catalog  = $json.catalog       || {};

let base = 0;
for (const s of services) {
  base += catalog[s] ?? 120;
}
if (base === 0) base = 120;

let travel = 20;
if      (zip === "76706") travel = 0;
else if (zip === "76708") travel = 10;

let subtotal = base + travel;
let rush = 0;
if (urgency === "high") {
  rush = Math.round(subtotal * 0.25);
}

return [{
  base_cost:   base,
  travel_fee:  travel,
  rush_charge: rush,
  total:       subtotal + rush,
  urgency:     urgency,
}];
agent-scheduling.json · Code in JavaScript 
// Read original webhook input via node reference
const preferred = $node["Webhook"].json.body.preferred_days || [];

const slots = [
  "Thu 4:30pm", "Thu 5:30pm",
  "Sat 9:00am", "Sat 10:30am",
  "Sun 1:00pm",
];

let filtered = slots;
if (preferred.length > 0) {
  filtered = slots.filter(
    s => preferred.some(d => s.startsWith(d))
  );
}

return [{
  proposed_slots: filtered.slice(0, 3),
  note: "Reply with a slot to confirm. Arrival window is 2 hours."
}];
agent-comms2.json · Build Prompt 
const job        = $json.body.job        || {};
const pricing    = $json.body.pricing    || {};
const scheduling = $json.body.scheduling || {};
const emailType  = $json.body.email_type  || "client";
const clientName = $json.body.client_name || "(not provided)";
const clientEmail= $json.body.client_email|| "";

let instructions;
if (emailType === "operations") {
  const reason = job.urgency === "high"
    ? "HIGH URGENCY"
    : "Estimate exceeds $300";
  instructions = "Write an internal notification email...\n"
    + "Reason: " + reason + "\n"
    + "Client: " + clientName
    + " (" + clientEmail + ")\n"
    + "Use a professional internal tone.";
} else {
  instructions = "Write a professional confirmation email.\n"
    + "IMPORTANT: Start with \"Hi " + clientName + ",\"\n"
    + "Summarize: service, address, cost, time slots.\n"
    + "End with next steps. Warm, professional tone.";
}
